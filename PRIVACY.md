# Politique de Confidentialité - n8n Manager

Dernière mise à jour : 10 février 2026

## Introduction

n8n Manager est une application mobile qui vous permet de gérer et surveiller vos instances n8n. Cette politique de confidentialité explique comment nous traitons les informations lors de l'utilisation de notre application.

## Collecte de Données

n8n Manager ne collecte, ne stocke ni ne partage aucune donnée personnelle. L'application fonctionne uniquement comme une interface pour communiquer directement avec votre propre instance n8n.

## Connexions

Toutes les connexions à votre instance n8n sont établies directement depuis votre appareil. Les informations de connexion (URL, clés API) sont stockées localement sur votre appareil et ne sont jamais transmises à des serveurs tiers.

## Autorisations de l'Application

L'application peut demander les autorisations suivantes :
- **Internet** : Nécessaire pour communiquer avec votre instance n8n
- **Stockage local** : Pour sauvegarder vos préférences et paramètres de connexion localement

## Sécurité

Nous prenons la sécurité de vos données au sérieux. Toutes les communications avec votre instance n8n doivent utiliser HTTPS pour garantir le chiffrement des données en transit.

## Services Tiers

Cette application ne fait appel à aucun service tiers d'analyse, de publicité ou de suivi.

## Modifications

Nous nous réservons le droit de modifier cette politique de confidentialité. Les modifications seront publiées sur cette page.
